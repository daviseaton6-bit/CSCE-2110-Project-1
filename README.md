# CSCE-2110-Project-1
Campus Resource Reservation System

To run the Campus Resource Reservation System, download or clone the project repository and make sure all source files and resources.txt are located in the project folder. Compile the program using g++ with the command g++ main.cpp Display.cpp QueueNStack.cpp reservation.cpp -o main.(outdated please view new code) After the program compiles successfully, run it on Windows using .\main.exe. The program will then display the main menu and allow the user to access the resource, reservation, waiting list, and cancellation features.
